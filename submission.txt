### Short Description (Elevator Pitch)
WhitehatAI is an autonomous emergency circuit breaker protocol that monitors DeFi contracts across Base, Arbitrum, and Ethereum. When an active exploit, reentrancy drain, or oracle manipulation is reported, GenLayer web-connected validators independently fetch the on-chain transaction trace, evaluate the vulnerability using LLM comparative consensus, and autonomously trigger an emergency pause on the target contract before remaining funds are drained.

### The Problem It Solves
Smart contract exploits drain millions in seconds because human multisig committees and security teams take hours or days to react. Today, protocols on Base or Ethereum cannot autonomously verify external web evidence or complex exploit receipts without centralized single points of failure.

### How It Uses GenLayer's Superpowers
1. Cross-Chain Adjudication: Implements GenLayer's "Build on Base / Arbitrum / Ethereum. Adjudicate on GenLayer" architecture. Contracts remain on Base or Arbitrum, while threat verification is offloaded to GenLayer.
2. Web-Connected Validators: GenLayer validators independently query block explorer traces (Basescan / Etherscan / Arbiscan) and security advisories without centralized oracles.
3. Multi-Model Comparative Consensus: Uses `gl.eq_principle.prompt_comparative` across multiple diverse AI models (Claude 3.5, GPT-5.4, Gemini 3 Flash) to verify unauthorized balance drainage and invariant violations.
4. Autonomous Execution: The contract transitions the target protocol into EMERGENCY_HALT with zero human voting, and awards the whitehat reporter a bounty from the protocol's security pool while slashing false alarm griefers.
